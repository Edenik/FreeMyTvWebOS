# Homebrew Channel listing

Everything needed to list Free My TV on the [webosbrew apps repository](https://github.com/webosbrew/apps-repo),
so Homebrew Channel users can install and update it from the TV.

1. Tag a release (`vX.Y.Z`, matching `app/appinfo.json`). `.github/workflows/release.yml` builds the ipk and
   attaches it plus `org.webos.freemytv.manifest.json` (generated by `scripts/make_manifest.py`, with the ipk's SHA-256).
2. Fork `webosbrew/apps-repo`, copy `org.webos.freemytv.yml` from this folder into its `packages/` directory, and open a PR.
   The PR must disclose any AI-tool use, per that repo's rules.
3. Later releases need no PR: `manifestUrl` points at the `latest` release asset.

Check the manifest fields against a current manifest in that repo before the first submission; the apps-repo README
does not define the schema.
